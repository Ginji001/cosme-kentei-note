# 日本化粧品検定1級 学習ノート（公開版）

日本化粧品検定1級（第27回・2026年11月29日）に合わせた、ビルド不要・外部CDNなしの学習管理PWAです。固定スケジュールの開始日と週の学習時間の目安は、設定画面で変更できます。

このアプリは**非公式の学習ツール**です。試験情報・学習内容は公式案内と公式テキストで確認してください。問題集や市販資料の本文は収録していません。

## できること

- 試験までの日数、当日のタスク、固定計画のチェックと週単位の計画表示
- 学習開始日と週の学習時間の目安の設定
- 問題記録、○△×の履歴、ミス分類、間違いノート、正答率集計
- 章まとめ、比較メモ、手元の製品表示を使った全成分分析
- 模試記録と正答率の推移、直前暗記カード
- JSONバックアップの書き出し・読み込み
- Service Workerによるオフライン利用と起動時の自動更新

## データについて

入力した記録・写真・設定は、このアプリ専用のIndexedDBに保存されます。サーバーには送信しません。ブラウザのデータを消すと記録も消えるため、必要に応じて設定からバックアップしてください。バックアップの読み込みは現在の記録を置き換えます。

## ローカルで開く

リポジトリのルートで次を実行し、表示されたURLをブラウザで開きます。HTMLを直接開かず、HTTPサーバーを使ってください。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

URLは `http://127.0.0.1:8765/` です。Service Workerとオフライン機能はHTTPまたはHTTPSで動作します。

## GitHub Pages

GitHub Pagesの公開元をこのリポジトリの `main` ブランチ・ルートに設定すると、`https://ginji001.github.io/cosme-kentei-1kyu-public/` で公開できます。静的ファイルをそのまま配信し、ビルドや外部CDNは使いません。

## 主なファイル

- `index.html`, `style.css`：画面とスタイル
- `js/app.js`：日本語UIと操作
- `js/domain.js`：日付、計画、履歴と集計
- `js/store.js`：IndexedDBとバックアップ
- `data/*.json`：試験情報、固定計画、学習用の空欄と一般的なヒント
- `sw.js`, `manifest.webmanifest`：PWA設定とオフラインキャッシュ
- `tests/acceptance.cjs`, `tests/schedule.cjs`：ブラウザ操作と日付計画の確認

ローカルでの確認は `node tests/schedule.cjs` および `node tests/acceptance.cjs` で実行できます。AcceptanceテストはPlaywrightとChromiumを使います。
